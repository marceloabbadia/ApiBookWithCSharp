📚 ApiBookWithCSharp – API REST para Gestão de Livros
Descrição:
API desenvolvida em C# com ASP.NET Core, focada na gestão de livros, com estrutura limpa e organizada para operações CRUD (Create, Read, Update, Delete).

Principais funcionalidades:

Cadastro de livros com título, autor e status

Endpoints RESTful para gerenciamento completo

Separação por camadas (Controller, Service, Repository)

Uso de Entity Framework e banco de dados relacional

Validação de dados e tratamento de erros

Tecnologias usadas:

C#

ASP.NET Core

Entity Framework Core

Swagger (para documentação de API)

SQL Server
